# MITM PlacePro — College Placement Portal

Industry-grade placement management system for MITM College built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- **4 Role-Based Dashboards**: Admin, Company HR, Student, Principal
- **Smart ATS Scoring**: AI-powered resume analysis
- **Automated Slot Allocation**: Conflict-free interview scheduling
- **Glassmorphism UI**: Premium modern design

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS v4
- Recharts
- Radix UI
- Lucide Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
